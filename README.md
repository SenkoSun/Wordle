# Wordle — игра в слова на 4 буквы

Монорепозиторий с полным вертикальным срезом: бэкенд на Spring Boot, фронтенд на React и база данных PostgreSQL. Проект демонстрирует продакшен-подход: чистая архитектура, REST API, JPA, CORS-настройка и адаптивный интерфейс.

## Ключевые сценарии

- **Игра в слова:** пользователь вводит слово из 4-8 букв, получает цветовую подсказку (зелёный — буква на месте, жёлтый — буква есть, но не на месте, серый — буквы нет).
- **6 попыток:** стандартное правило Wordle — 6 попыток, чтобы угадать слово.
- **Физическая и экранная клавиатура:** поддержка ввода с реальной клавиатуры и экранных кнопок.
- **Мгновенная обратная связь:** после каждой попытки ячейки окрашиваются в соответствии с результатом.

## Технологический стек

### Backend
- **Java 25** + **Spring Boot 4.1.1**
- **Spring Data JPA** — работа с базой данных
- **PostgreSQL** — реляционная база данных
- **Lombok** — уменьшение шаблонного кода
- **Maven/Gradle** — сборка проекта

### Frontend
- **React 18** + **Vite** (или Create React App)
- **Axios** — HTTP-запросы к бэкенду
- **CSS Modules** — изолированные стили
- **React Hooks** — управление состоянием
